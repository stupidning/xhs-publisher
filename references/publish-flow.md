# 发布页怎么操作

发布前先读这个文件。

## 前置检查

1. 浏览器扩展能用（能打开网页就算能用）
2. 打开 `https://www.xiaohongshu.com`，右上角有头像 = 已登录；有登录弹窗 = 没登录，对使用者说：
   > 请扫码登录小红书，登录好告诉我。
3. 多个账号的使用者，确认这次发的是哪个号（看头像/昵称）

## 逐步操作

1. **打开发布页**：`https://creator.xiaohongshu.com/publish/publish?source=official`
   - 如果跳到视频发布，手动切到「上传图文」
2. **上传图片**：用使用者回传的本地图片，一张一张传，等缩略图出来再传下一张
   - 传完核对：数量对不对、**第一张是不是封面**，顺序错了当场拖动调整
   - 比例不是 3:4 的，告诉使用者会怎么被裁
3. **填标题**：≤20 字，填完核对输入框内容跟确认稿一致（个别 emoji 输不进去就换成文字）
4. **填正文**：≤1000 字，分段、emoji、话题都要在
5. **加话题**：正文里的 #话题 会出联想，从联想列表里点真实存在的，别硬打
6. **其他设置**：地点、合集、定时发布保持默认，除非使用者明确要求；**不碰任何付费推广功能**
7. **最终确认**：整页截图发给使用者：
   > 这是最终效果，确认没问题我就点发布了。
8. **点发布**：使用者同意后才点，等跳转到成功提示
9. **验证**：打开笔记页，确认标题、图片、正文真的能看到，把链接发给使用者
10. **记录**：往 `assets/publish-log.jsonl` 追加一行：`{"date":"...","title":"...","url":"...","status":"published|failed","note":"..."}`

## 出问题了怎么办

| 情况 | 怎么处理 |
|---|---|
| 出现验证码/滑块 | 马上停，对使用者说「需要你手动过一下验证，过了告诉我」，不自动过验证 |
| 图片传不上去 | 等 10 秒重试一次；还不行就停，检查格式（jpg/png，单张 ≤32MB）后告诉使用者 |
| 标题被截断 | 回第 3 步改短，重新给使用者确认 |
| 点发布没反应 | 等 5 秒截图看状态，**不连点**；还是没反应就告诉使用者 |
| 提示"操作频繁" | 当天停止发布，如实说明，建议隔天再发 |
| 页面改版找不到按钮 | 截图说明现状，跟使用者商量手动发的降级方案，并把改版情况记进发布日志 |

## 节奏

- 每个动作之间隔 1~3 秒，别像机器人一样连点
- 全程超过 15 分钟说明有问题，停下来排查
- 一次会话只发一篇
