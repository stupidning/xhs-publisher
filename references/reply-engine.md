# 自动回复怎么回

自动回复分两块：**回什么**（内容）和**什么时候回**（调度）。开启前先跟使用者把下面的话确认一遍。

## 开启前对使用者说

> 自动回复这么设可以吗？
> - 每 30 分钟查一次新评论和私信
> - 语气按你的人设档案来
> - 晚上 11 点到早上 8 点不回，第二天早上统一补
> - 广告、杠精不回；谈价格、售后的转给你本人处理
> - 每天最多回 50 条评论、20 条私信

## 回什么

### 评论

| 评论类型 | 怎么回 |
|---|---|
| 提问（怎么买、哪里买、怎么用） | 按人设档案里的商品信息如实回答；档案里没有的就说「我确认下回复你」，标记转人工，**不编** |
| 夸赞、共鸣 | 短句互动，带人设语气，可以反问一句引导再聊 |
| 问价格 | 档案里有话术就按话术，没有就引导私信、转人工 |
| 差评、吐槽 | 不争辩、不删评，礼貌接住问题并引导私信解决，标记转人工 |
| 广告、同行引流 | 不回 |
| 杠精、辱骂 | 不回（使用者要求的话可以拉黑） |
| 医疗功效、金融承诺、要微信/站外链接 | 不回，标记转人工 |

### 私信

- **只回别人发来的，绝不主动群发**（群发最容易触发风控）
- 第一条：打招呼 + 回答对方的问题
- 同一个人 24 小时内最多再追 1 条，不骚扰
- 谈价格、售后、大额订单：礼貌接住，标记转人工
- 引导站外交易、收款：一律不承诺，转人工并提醒使用者平台规则风险

## 什么时候回（默认参数，使用者可改）

```
回复时段      08:00–23:00
静默时段      23:00–08:00 完全不回，积压到次日 08:30 后补
高峰          12:00–14:00、18:00–23:00 优先回
检查频率      每 30 分钟一次（可选 1 小时 / 随机 20–60 分钟）
每次上限      最多 8 条，剩下的下一轮
单条间隔      随机 2–6 分钟
防秒回        新留言等 5–15 分钟再回
每天上限      评论 ≤50 条，私信 ≤20 条
```

**为什么这么设**：固定整点回复最容易被认成机器人，随机间隔才像人；深夜秒回一样会露馅；30 分钟响应已经能吃到平台的互动权重。

**夜间留言**：第二天早上按留言时间顺序、正常间隔逐条补回，别说「抱歉昨晚没回」这种暴露自动化的话，直接接着内容回。

## 定时任务怎么配

用 WorkBuddy 定时任务触发本技能，任务名建议「小红书互动检查」：

- 周期按上面选的检查频率
- 提示词要点：加载本技能 → 查新评论和私信 → 按策略回或标记转人工 → 记录到 `assets/reply-log.jsonl`（时间、类型、昵称、原文摘要、回复内容或"转人工"）
- 每轮结束给使用者一句简报：回了几条、几条转人工

## 不能碰的线

- 不承诺收益/功效、不发站外链接、不引导加微信、不报没授权的价格
- 同一条留言绝不重复回（回之前先查 reply-log）
- 看到限流、禁言警告：当天停止互动，报告使用者
- 转人工的条目单独列出来，别让使用者漏掉重要客户

## 使用者的设定（确认后记这里）

- 检查频率：待定
- 回复时段：默认 08:00–23:00
- 人设档案：待填
- 是否拉黑杠精：待定
